# AI 应用开发实习准备要点

## 简历
- 项目经历 > 课程成绩。面试官看你做过什么、能不能讲清楚。
- 至少有一个完整的端到端项目:能本地跑、有 README、有演示动线。
- 写清楚:用了什么技术栈、你负责什么、解决了什么问题、量化结果。

## 技能
- Python 必会;Web 框架至少一个(Flask / FastAPI)。
- 至少调通一次 LLM API(OpenAI / 智谱 / DeepSeek)。
- 向量数据库基础(Chroma / FAISS)。
- 会读文档、能在 GitHub 上搜代码、能在 StackOverflow 提好问题。

## 面试常问
- 讲一个你做的项目,深挖技术选型和难点。
- RAG 是什么?为什么要用向量检索?chunk 怎么切?
- 怎么评估一个 LLM 应用的质量?
- 你最近看了什么 AI 相关的资料?能不能讲讲?
